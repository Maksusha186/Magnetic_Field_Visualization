# gunner - визуализация магнитного поля

Программа для расчёта и 3D-визуализации магнитного поля в сечении осесимметричного соленоида. Реализует численное интегрирование силовых линий методом Рунге-Кутты 4-го порядка и интерактивное управление параметрами поля.

## Демонстрация

![Скриншот](image.png)

## Возможности

- Расчёт магнитного поля от токовых обмоток.
- Построение силовых линий методом RK4 с адаптивным шагом.
- Визуализация распределения поля в виде тепловой карты.
- 3D-отображение геометрии катушек и силовых линий.
- Интерактивное управление параметрами: ток (Current, A), количество витков (Turns count), геометрия (внутренний/внешний радиус, высота).
- Переключение видов: Front, Side, Top.
- Валидация расчётов (Validation Tests).

## Сборка

Требования: CMake 3.15+, Visual Studio 2022 (или GCC/Clang), GLFW 3.4, GLM 1.0.2, OpenGL.

Команды:

```
mkdir build
cd build
cmake .. -G "Visual Studio 17 2022" -A x64
cmake --build . --target gunner --config Release
```
## Запуск

build/Release/gunner.exe
